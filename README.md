# PokéFinder

## Autor

Lukas Ferreira de Souza — Matrícula: 22609192

## Descrição

O PokéFinder é uma aplicação web que permite pesquisar Pokémon pelo nome ou número e visualizar informações como nome, imagem, tipo, altura e peso.

## API utilizada

- PokeAPI
- Documentação: https://pokeapi.co/
- Endpoint utilizado: https://pokeapi.co/api/v2/pokemon/{nome}

## Funcionalidades

- Pesquisa de Pokémon pelo nome ou número.
- Exibição da imagem do Pokémon.
- Exibição do tipo.
- Exibição da altura.
- Exibição do peso.
- Exibição do número do Pokémon.
- Mensagem de erro para Pokémon não encontrado.
